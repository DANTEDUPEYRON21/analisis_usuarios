# 📊 Proyecto: Análisis del Comportamiento de Usuarios en App de Comida  

Este proyecto analiza el comportamiento de los usuarios dentro de una aplicación de una empresa emergente de productos alimenticios. El objetivo es entender el **flujo de conversión** y evaluar el impacto de un experimento **A/A/B** en la experiencia de usuario.  

---

## 🔍 1. Análisis del Embudo de Ventas  
- Se examinan los eventos registrados por los usuarios para identificar cuántos completan el embudo de conversión.  
- Se detectan puntos de fricción: dónde se pierden más usuarios y en qué etapa del proceso.  
- Se cuantifica la eficiencia del embudo y se proponen mejoras en el producto.  

---

## 🧪 2. Test A/A/B  
- Se analizó un experimento con tres grupos: **dos de control (fuente antigua)** y **uno de prueba (fuente nueva)**.  
- Se evaluó si la nueva fuente afecta negativamente el comportamiento de los usuarios.  
- Se aplicaron pruebas estadísticas (**z-test y t-test**) para validar la significancia de los resultados.  

---

## 📁 Estructura del proyecto  
- `proyecto_11.ipynb`: notebook principal con el análisis completo.  
- `logs_exp_us.csv`: archivo de eventos de usuarios (cargado en el notebook).  

Los gráficos, pruebas estadísticas y conclusiones están documentados dentro del notebook.  

---

## 🛠 Herramientas utilizadas  
- **Python**: pandas, numpy, seaborn, matplotlib  
- **Estadística**: z-test, t-test  
- **Entorno**: Jupyter Notebook  

---

## ✅ Conclusiones y Recomendaciones  
- Se identificaron etapas críticas donde los usuarios abandonan el embudo.  
- El experimento A/A/B mostró resultados consistentes, sin evidencia de un impacto negativo de la nueva fuente.  
- Este análisis puede guiar decisiones de **UI/UX**, optimización de **onboarding** y mejoras en el **flujo de ventas**.
